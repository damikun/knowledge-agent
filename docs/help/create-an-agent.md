# Create an agent

An agent is the brain behind a widget: what it knows, how it talks, its tools and when it offers a person. Create one on [Agents](/agents/new); each widget answers with one agent.

## Create an agent

1. Open [Agents](/agents/new) and press New agent, or start from a template.
2. Give it a name, a purpose and the language it answers in (or the visitor's own).
3. Choose its tone and describe how it talks the way you would brief a new colleague.
4. Choose what it knows: all your sources, or only some folders.
5. Choose its tools, the connected apps it may use and when it offers a person.
6. Save, then try it in the [Playground](/playground).

## The tabs of an agent

Open an agent on [Agents](/agents) to see its Overview and its tabs:

- General: name, purpose and language.
- Behavior: tone and instructions.
- Knowledge: all sources or chosen folders, and whether it may fill gaps from general knowledge. Sources filed in those folders later count too.
- Tools: its built-in abilities, and the connected apps (MCP servers connected on [Tools](/tools)) it may use. Turn an app on and it uses all of the app's tools, also ones the app adds later; under Choose tools you can limit it to the tools you pick.
- Handover: when to offer a person (never, only when asked, or also when it cannot answer).
- Specialists and Use elsewhere: other agents it hands off to, and its MCP server and HTTP API.
- Advanced: its model.

## Test it in the Playground

The [Playground](/playground) tests your own agents, the first one unless you pick another. With no agent yet, it leads you to New agent. Questions about the portal itself go to the help assistant, the "?" in the header.

## Duplicate or delete an agent

Use the menu on the agent's page. An agent that a widget uses cannot be deleted; move the widget to another agent first ([Widgets](/widgets)).
